    Mes données

    Bienvenue ! L’application démarre vide. Importez votre fichier de départ (mes-donnees-pokehub.json) avec « Importer un fichier », ou connectez la synchronisation si vous l’avez déjà configurée sur un autre appareil.

    Où j’en suis

      Le navigateur bloque le stockage local : rien ne sera conservé. Exportez une sauvegarde avant de quitter.

      Synchronisation automatique

      PC et téléphone se mettent à jour tout seuls, grâce à un fichier dans un dépôt GitHub privé à vous. Sans votre jeton, personne ne peut lire ni modifier vos données.

      Comment faire (5 minutes, une seule fois)
      1. Sur github.com, créez un dépôt privé (par exemple pokehub-donnees) en cochant « Add a README ». Ce n’est pas le dépôt du site.
      2. Allez dans Settings, Developer settings, Personal access tokens, Fine-grained tokens, puis Generate new token.
      3. Repository access : Only select repositories, puis ce dépôt privé. Repository permissions : Contents : Read and write. Expiration : la plus longue proposée.
      4. Copiez le jeton (il ne s’affiche qu’une fois), puis collez-le ci-dessous avec le nom du dépôt. Faites de même sur chaque appareil, avec le même dépôt et le même jeton.

      Connecté au dépôt . Les changements partent tout seuls quelques secondes après chaque modification.

      Quand j’importe des données…

      Ce choix s’applique au fichier et au code ci-dessous.

      Sauvegarde dans un fichier

      Un fichier à garder (cloud, mail à soi-même) : il contient vos shiny, vos cartes et votre journal.

      Passer du PC au téléphone

      Sans fichier : copiez le code, envoyez-le-vous (message, note), puis collez-le dans l’autre appareil.

      Installer sur le téléphone

      1. Mettez le dossier pokehub en ligne (GitHub Pages, Netlify ou Cloudflare Pages, gratuits) : vous obtenez une adresse https.
      2. Ouvrez cette adresse sur le téléphone.
      3. Android (Chrome) : menu ⋮, puis « Installer l’application ». iPhone (Safari) : Partager, puis « Sur l’écran d’accueil ».

      Ensuite elle s’ouvre comme une application et marche sans internet. Sur iPhone, installez-la : sinon Safari peut effacer les données après quelques semaines sans visite.
